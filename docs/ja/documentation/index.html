Ferocity 波形の幾何学

Ferocity は半ストロークの性格とタイミングの両方を制御します。内部的には WebUI の 0–100 設定が 0–8 にマッピングされます。ダウンストロークの Ferocity が高いほど周期に占めるダウンストロークの割合が短くなり、復路の Ferocity が高いほど復路の割合が短くなります。残りの時間は反対側の半周期へ移ります — ゼロでの停止はありません。

プロファイルごとの Ferocity Shape コントロールは、高 Ferocity の性格を選択します。0% では有限のプラトー／矩形形状を、100% では丸みを帯びたピラミッド状の経路を好みます。各半周期は依然として独自の Ferocity を使うため、低 Ferocity の半周期は伸長して正弦波的になり、高 Ferocity の半周期は直接的な対角線の走行に近づきます。

極端な組み合わせを読む

7 / 1 の組み合わせは、明らかに短く尖ったダウンストロークと長い正弦波の復路を生みます。正確な値やほぼ最大の値には注意が必要です。現在の持続時間則は ferocity 8 未満の残量を使います。そのため 8 / 0 は周期の約 0.125% しかダウンストロークに割り当てず、8 / 6 でさえ約 0.5% を割り当てます。位置は連続的ですが、要求される速度と加速度は物理的に到達不能になり得ます。

飛行前にベンチテストを。 エクスプローラーは保証されたサーボ動作ではなく、指令された数学的な波形を表します。振幅、周波数、リンケージ形状、サーボ速度限界が空力負荷なしで検証されるまで、極端な非対称設定は避けてください。
