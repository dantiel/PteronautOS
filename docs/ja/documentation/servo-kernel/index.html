サーボカーネル

パルス幅エンベロープ、機能別トリム、速度制限 — 低レベルサーボ契約。

パルス幅エンベロープ

サーボカーネルは、<code>servoMinUs</code>(デフォルト <strong>988</strong>)と<code>servoMaxUs</code>(デフォルト <strong>2012</strong>)で定義されるグローバルなエンベロープを通じて、正規化角(−1…+1)をパルス幅にマッピングします。これは旧来のコンパイル時定数を置き換え、0°/180°のスイングを再ビルドなしで任意のサーボに合わせられます。値は<code>[500…1490]</code>と<code>[1510…2500]</code>にクランプされ、<code>min &lt; max</code>が強制されます。

機能別トリム

<code>servoTrimUs[]</code>はミキシング後に適用される<em>ServoFunc</em>ごとの補正(±300&nbsp;µs)です。翼ペア(インデックス 1/2)、ラダー(3)、後翼(8/9)をカバーします。単一舵面の半歯分のホーンオフセットをゼロにするために使います。機体の不均衡を直すためのものではなく、それはミキサーかジャイロの役目です。

速度制限

<strong>サーボ速度</strong>はティックごとのパルス変化率を制限し、急激な反転を滑らかにしてギアボックスを衝撃荷重から守ります。これは指令位置に対するローパスなので、低い値はフラップ反転も和らげます。ストローク上端と下端の<em>クリック</em>音に合わせて調整してください。遅すぎると翼が波形に遅れ、速すぎると衝撃が戻ります。

パルス/トリム/速度パラメータと JSON キーの全一覧は、ファームウェア内のサーボカーネルノートと WebUI リファレンスを参照してください。
