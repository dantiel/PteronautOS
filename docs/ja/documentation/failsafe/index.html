フェイルセーフ動作

リンク喪失時に何が起きるか — 翼のセンター、舵のセンター、優雅な縮退。

トリガー条件

フェイルセーフは、CRSF リンクが接続喪失を報告したか、チャンネルデータが設定タイムアウトを超えて古くなったときに作動します。無線機自身のフェイルセーフは<em>真実の源ではありません</em>。PteronautOS は独自の中央フェイルセーフを再適用するため、無線機のブランドやバインドモードに関係なく動作は同一です。

センター出力

トリガー時、全サーボが <strong>1500&nbsp;µs</strong> に戻り、波形出力は抑制されます。翼は中央に、クレストラダーは中央になります。<code>voiceAileron/Elevator/Throttle/Rudder</code> のチャンネル読み値がリセットされ、WebUI 状態ポーリングが中立の真実を示します。

優雅な縮退

設計規則は<em>劣化における優雅さ</em>です。故障した MPU6050 が機体を墜落させてはなりません。Zephyrus はジャイロ故障時に自ら無効化し、Ornithopter ミキサーは純粋なスティック入力で飛行を続けます。フェイルセーフ経路とジャイロ経路は独立しているため、一方の故障が他方へ連鎖することはありません。

回復

復旧は自動です。有効な CRSF フレームが再開すると、ミキサーは次のティックで再び関与し、サーボはライブチャンネルを再び追従します。手動リセットもラッチもありません。移行は指令位置へ戻る単一のソフトランプです。

飛行前にベンチテストを。 エクスプローラーは保証されたサーボ動作ではなく、指令された数学的な波形を表します。振幅、周波数、リンケージ形状、サーボ速度限界が空力負荷なしで検証されるまで、極端な非対称設定は避けてください。
