波形チューニング

フェロシティ、振幅、周波数、グライド角で羽ばたきを成形し、翼と機体に合わせます。

パラメータをライブで試すには フェロシティ波形エクスプローラー で確認してからファームウェアを変更してください。同じモデルがミキサーを駆動します。

フェロシティ（ストローク非対称）

フェロシティはストローク/復帰の非対称です。0 では波は純粋なサイン波で、上下の時間は等しくなります。ダウンフェロシティを上げるとダウンストロークが速くなりアップストロークのドウェルが長くなります(アップフェロシティはその逆)。これは推力が生まれる場所を移します。速いダウンストローク + 遅い復帰は本物の鳥のパワーストロークを模倣し、最も効果的なフィーリング変化です。

力強いダウンストロークのために down 8, up 0 から始め、アップフェロシティを小さなステップで混ぜます。非対称が過剰だと反転時に翼がスナップします。クリック音として聞こえ、サーボの発熱として見えます。

振幅と周波数

振幅は直接設定されません。周波数とストローク速度から生じます。フラップ周波数を上げると所与の速度でストロークが短くなり、下げると長くなります。カーネルはサーボが 988–2012 µs のエンベロープを決して出ないよう振幅を制限します。機体の自然なフラップ共振に周波数を合わせてください。高すぎる周波数はエネルギーを浪費し、低すぎる周波数は有効揚力を下回ります。

シェイプミックススライダーは純粋なサインを台形へブレンドします(反転点でのドウェル増加)。ミックスが高いほど反転が鮮明で両端の推力が増します。ミックスが低いほど滑らかで効率的な巡航になります。

グライド角と羽ばたき角

グライド角とフラッピング角はどちらも中心オフセット(int8, ±15°)であり、振幅ではありません。グライドはスロットルがグライドを指令するときの共通翼角を設定し、フラッピングはフラップストロークの中心をずらします。機械的リンケージに触れずに、低速飛行と高速巡航で翼を偏らせられます。

初期プリセット

プリセット ダウン / アップ ミックス 特性
エクストリーム 8 / 0 100% 強いパワーストローク、攻撃的
準サイン 7 / 1 100% バランス型、最も自然
高ドウェル 8 / 6 100% 長い反転ドウェル、ふわふわ
ミックス 8 / 6 50% ソフトブレンド、巡航効率

準サインから始めて安定飛行を確認し、パンチが欲しい場合のみ エクストリームへ進みます。どの機体も異なる最適点を持ちます。一度に 1 つのパラメータだけ変えてください。
