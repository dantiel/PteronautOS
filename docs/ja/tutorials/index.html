チュートリアル

ハードウェアの準備、ハーメティック・ファームウェアの導入、新しい PteronautOS 機体を稼働させるための実用ガイド。

PteronautOS は従来型のマルチローター・スタックではありません。CRSF 制御を 2 つの翼サーボとクレストラダーのための協調した羽ばたきへ変換します。ゼピュロスによる安定化はオプションであり、優雅に機能低下します。

まず下のフラッシュガイドから始めてください。以降のガイドでは受信機の配線、バインディング、初めての制御された羽ばたき、WebUI による波形の調整を扱います。どの手順もプロジェクトの核となるルールを守ります: 決定的なタイミング、中立のフェイルセーフ動作、飛行ループ内でのブロッキング作業の禁止。
