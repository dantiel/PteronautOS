チュートリアル 08

Pteronaut-EggでWiFiフラッシュ

完全にWiFiでフラッシュ＆アップデート — ケーブル不要、FTDI不要、UART不要、永久に。

Pteronaut-Eggは受信機に常駐する小さなWiFiブートストラップ（約294 KB）です。その唯一の役割は、完全なPteronautOSファームウェアをWiFiで受け取って準備すること — だからケーブルは一切不要です。

ESP8285のフラッシュ領域は約1 MBが1つだけです。完全イメージ（約636 KB）は自身の空きステージング領域に収まらないため、WiFiで自己更新できません。Eggは収まるほど小さく、完全イメージはEggを書き戻せるほど小さい — 無限のEgg ↔ 完全サイクルが閉じます。

01 — Eggを入手

ビルド済みのPteronaut-Eggイメージをダウンロードします。設定に依存しない固定ブートストラップで、設定もビルドも不要です。

pteronaut-egg.bin.gzをダウンロード

02 — エッグを書き込む（初回）

受信機には標準の ExpressLRS が搭載されています（エッグではありません）。エッグを一度だけ、完全に WiFi 経由で、受信機自身の WebUI からインストールします。ケーブルは一切不要です。

受信機に電源を供給します。標準 ExpressLRS が WiFi アクセスポイントを開きます。下記のデフォルトの ExpressLRS 認証情報で接続し、WebUI を開きます。

項目 値
WiFiネットワーク (AP) ExpressLRS RX
WiFiパスワード expresslrs
アップロードページ WebUI → Firmware Update

ダウンロードした pteronaut-egg.bin.gz を pteronaut-egg.bin に解凍し、Firmware Update ページでアップロードして、受信機がエッグに再起動するのを待ちます。

03 — 完全なファームウェアを入手

完全ファームウェアはFossil Etcherで毎回新しくビルドされます。受信機・ミキサー・設定を選び、最新イメージをブラウザから直接ダウンロード。PlatformIO不要。

Fossil Etcherを開く

Etcherは毎回ソースから現行のPteronautOSをビルドするので、常にベストプラクティスの既定値が入った最新ファームウェアが手に入ります。

04 — エッグに接続

受信機に電源を供給します。エッグが WiFi アクセスポイントを開きます; 下記の認証情報で接続し、ブラウザでアップロードページを開きます（pteronaut-egg.local、またはフォールバックとして 192.168.4.1）。

項目 値
WiFiネットワーク (AP) PTERONAUT-EGG
WiFiパスワード hatchnatural
アップロードページ pteronaut-egg.local

05 — 完全なファームウェアをアップロード

Eggのアップロードページで、Fossil Etcherからダウンロードした完全ファームウェアをASCII Eggの上へドラッグします。Eggがそれを準備し、完全なPteronautOSへ再起動します。

06 — 今後のすべての更新

これからはアップデート＝WiFiアップロード２回＋ケーブル０本。完全なPteronautOSは標準のELRS WebUIを実行します。Firmware Updateページを開き、Eggを書き戻してから新しい完全ファームウェアをアップロード。サイクルは無限に繰り返されます。

WiFiネットワークの比較

各段階は独自の WiFi ネットワークとパスワード、異なるアップロードページを使用します。完全なマップはこちら:

段階 WiFiネットワーク (AP) パスワード アップロードページ
標準 ExpressLRS（受信機に搭載） ExpressLRS RX expresslrs WebUI → Firmware Update
Pteronaut-Egg PTERONAUT-EGG hatchnatural pteronaut-egg.local
完全な PteronautOS Pteronaut OS flynatural WebUI → Firmware Update

ブリックリスク（正直に）

どの無線フラッシュも同じで、WiFiが全く起動しない壊れた完全イメージだけが有線復旧を強制します。通常使用ではEggがケーブルを完全に排除 — ケーブル不要、永久に。

Fossil EtcherはWiFiとUARTの両ワークフローに対応する共通フラッシュツールです。Eggの入手も完全ファームウェアのビルドも、すべてブラウザから。
