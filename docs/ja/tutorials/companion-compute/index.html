コンパニオン・コンピュート・モード

剣に手を: RP2040-Tiny をコンパニオン・コアとして配線しよう。

必要なもの

  • Waveshare RP2040-Tiny — 手
  • MPU6050 ジャイロ(GY-521) — I2C
  • サーボ三つ — 翼 左/右、冠舵
  • コンパニオン・ブリッジで書き込まれた PteronautOS 受信機

ジャイロを配線する

MPU6050 は受信機ではなく RP2040 の I2C — SDA と SCL — に直接つなぐ。ジャイロは手に属する。

両ボードを書き込む

PteronautOS を通常どおり書き込み、次に RP2040-Tiny 用の YOSHIMITSU スケッチを書き込む。従者の手は MUSHIN(無心)コマンドで目覚める——一つのファームウェア、一つの巻物。

MUSHIN を武装する

MUSHIN(無心)は標準で武装したまま起動する——手は思考より先に打つ。USB コンソールを開き、MUSHIN で報告、MUSHIN ON/OFF で武装・解除する。再書き込みは不要: 選択はフラッシュに残り、MEDITATION のフラッシャー・ブリッジは決して触れられない。

確認

USB コンソールを開き、JIGUANG の物語を読む: 構えは MEDITATION、ブリッジは立っており、ジャイロは受信機ではなく手から報告する。
