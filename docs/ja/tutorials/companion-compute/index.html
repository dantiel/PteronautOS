コンパニオン・コンピュート・モード

剣に手を: RP2040-Tiny をコンパニオン・コアとして配線しよう。

必要なもの

  • Waveshare RP2040-Tiny — 手
  • MPU6050 ジャイロ(GY-521) — I2C
  • サーボ三つ — 翼 左/右、冠舵
  • コンパニオン・ブリッジで書き込まれた PteronautOS 受信機

ジャイロを配線する

MPU6050 は受信機ではなく RP2040 の I2C — SDA と SCL — に直接つなぐ。ジャイロは手に属する。

両ボードを書き込む

PteronautOS を通常どおり書き込み、次に RP2040-Tiny 用の YOSHIMITSU スケッチを書き込む。コンパニオン・コアは二つ目のファームウェアイメージではなく管理者フラグで有効になる。

コンパニオン・モードを有効にする

スケッチで COMPANION_MODE を 1 にし、再ビルドして書き込む。再起動すれば手が目覚める。

確認

USB コンソールを開き、JIGUANG の物語を読む: 構えは MEDITATION、ブリッジは立っており、ジャイロは受信機ではなく手から報告する。
