02

初飛行とサーボ設定

翼をセンターに合わせ、方向を設定し、エンドポイントを調整して初飛行を成功させましょう。

1 · サーボのセンター調整

無線機をバインドした状態で、スティックは中立にして受信機に給電してください。全サーボは 1500 µs に位置する必要があります。ホーンがリンケージに垂直でない場合は、ねじを外して最も近いスプラインに付け直してください。無線機のサブトリムで中立を強制しないでください。フライトコントローラはすでに真の 1500 µs 中心を想定しています。

翼ペアが重要です。両翼は中立で同じ幾何学的角度になければなりません。左右の半歯の差は飛行中のロール偏りとして現れ、ジャイロの権威を削らずにトリム除去することはできません。

2 · 方向と逆転

スティック 期待される舵面
右ロール 右翼端が上、左翼端が下
ピッチアップ(引く) 機首を上げるよう両翼が傾く(またはエレボン相当)
右ヨー クレストラダーが右に振れる

舵面が逆向きに動く場合は、サーボを反転させたり 988–2012 µs マップをずらす無線チャンネルリバースを使うのではなく、フライトコントローラ設定(サーボカーネルの方向フラグ)で反転してください。無線出力は 1500 µs を中心に対称に保ちます。

3 · エンドポイントとリミット

サーボカーネルのデフォルトは servoMinUs 988 と servoMaxUs 2012 です。翼が極端位置で突っ張らずに全行程を掃引するよう機械的エンドポイントを設定してください。ストールしたサーボのブザー音を聞き、止まるまでエンドポイントを戻します。エンドポイントは無線機ではなくサーボカーネルにあります。無線機は ±100% のままにします。

4 · 飛行前チェック

  • 中立で翼中央、両方向とも正しい。
  • ストールのブザー音なくエンドポイント設定。
  • フェイルセーフ確認 — 送信機オフ — 翼とラダー中央。
  • ジャイロが正しい向きで反応(機体をロールさせるとラダーが逆らう)。
  • バッテリー電圧が BEC 定格と一致。フルスイープでサーボがブラウンアウトしない。

5 · 初飛行

まず モーター/フラップオフで緩やかなグライドに手投げし、トリムとバランスを確認してください。まっすぐ滑空するようになってから、低いフラップ周波数と低いフェロシティを投入します。周波数はゆっくり上げてください。共振と空力弾性効果は対気速度で変わるため、変更ごとに再トリムします。最初のバッテリーでは早めに着陸してください。目的はデータであって滞空時間ではありません。
