03

送信機の設定

ELRS無線機をバインドし、4つの制御チャンネルを割り当て、サーボカーネルに合うエンドポイントを設定します。

バインド

受信機をバインドモードにし(設定したバインドフレーズで給電、または WebUI / ボタンを使用)、無線機で <strong>Bind</strong> アクションを開始してください。デフォルトのバインドフレーズ <code>darographix</code> は固定 UID を生成します。バインド成功は、点灯し続けるリンク LED と WebUI 状態ポーリングでのライブチャンネル動作で確認されます。

チャンネル割当

無線チャンネル PteronautOS の役割
CH1 エルロン(ロール)
CH2 エレベーター(ピッチ)
CH3 スロットル(フラップ駆動)
CH4 ラダー(ヨー/クレスト)

4 つのコントロールをその順序でマッピングしてください。PteronautOS は CRSF 順で読み取るため、CH1–CH4 をデフォルトの AETR レイアウトに保ちます(設定で並べ替えた場合はミキサーが期待するものに合わせます)。

エンドポイントと方向

無線出力を <strong>±100%</strong> に設定します(CRSF 172–1811&nbsp;µs、992&nbsp;µs 中心)。拡張リミットは<em>使わないでください</em>。サーボカーネルはすでに 988–2012&nbsp;µs のパルスエンベロープ全体をマッピングしており、無線をクリップするのは解像度を無駄にするだけです。サブトリムはゼロのままにします。中立は設計上 1500&nbsp;µs です。

レートとエクスポ

<strong>100% レートと 0% エクスポ</strong>から始めます。フラップの権威はスティックの振り幅ではなく波形振幅が支配するため、攻撃的な無線レートは機体をびくびくさせるだけです。うまく滑空・羽ばたくようになったら、柔らかい中心のために穏やかなエクスポ(15–25%)を加え、ロール応答が翼を過剰に指令する場合のみレートを下げてください。

検証

  • スティック全右 — 右翼が上がり、左翼が下がる。
  • スティック全後(ピッチアップ)— 両翼が機首を上げる。
  • スロットルアップ — フラップ周波数が増加。ダウン — 減少またはグライド。
  • ラダー右 — クレストが右に振れる。
  • 送信機オフ — 全舵面が中央(フェイルセーフ)。
