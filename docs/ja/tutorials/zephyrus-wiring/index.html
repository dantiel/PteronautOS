ゼピュロス・ジャイロ配線

MPU6050をI2Cバスに配線し、ピン競合を解決し、シリアルログでAHRSを検証します。

I2Cピン選択

Zephyrus のデフォルト I2C ピンは GPIO4 (SDA) と GPIO5 (SCL) です。PWMP7 v1.0 では問題ありません。v1.1 では GPIO2/GPIO5 が引き出されていないため、Zephyrus は GPIO1 (SDA, CH2) と GPIO3 (SCL, CH3) を使います。必ずシルクスクリーンをピンマップと照合してください。GPIO4 は SX1280 無線割り込み用にハード予約されており、絶対に転用してはいけません。

GY-521の配線

GY-521 受信機
VCC 5V レール(オンボードレギュレータが 3.3V 生成)
GND GND
SDA GPIO1 (CH2) — v1.0 では GPIO5
SCL GPIO3 (CH3) — v1.0 では GPIO2
AD0 / INT / XDA / XCL 開放のまま

GY-521 は独自の 4.7 kΩ プルアップと AMS1117-3.3V レギュレータを搭載しています。5V を供給すれば自前の 3.3V を作り、ロジックレベルは自動で一致します。合計 4 本のワイヤ、トレース切断なし、追加レギュレータなし。

キャリブレーションと検証

Mahony AHRS は起動時にジャイロバイアスを自己較正します。電源投入後 1 秒間は機体を静止させてください。シリアルログでセンサーが生きているか確認します。傾けるとピッチ/ロールが機体に追従し、クレストラダーが手動ロールに逆らうべきです(右ロール → ラダーは左に補正)。起動時にバスがハングしたら、予約済みピンに当たっています。マップを再確認し、正しい CH2/CH3 ペアへ移してください。
