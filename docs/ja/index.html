ESP8285 · CRSFプロトコル

01 本質

PteronautOSはExpressLRSの上に構築され、オーニソプター用フライトコントローラーへと変貌を遂げた。

クアッドではない — モーターもESCもBetaflightもない。動作は波形によって生成され、二つの翼サーボとクレストラダーサーボを駆動する。

CRSF（無線） → rx_main → Ornithopter → 波形 → PWMサーボ

03 Zephyrus ジャイロモジュール

MPU6050による頭蓋冠ラダー安定化。Mahony AHRSによる姿勢推定、ロール角とヨーレート補正のためのデュアルPID。

センサー MPU6050 (GY-521)
インターフェース 直接I2C (GPIO1/GPIO3)
AHRS Mahony（レジスタレベル、約1kHz）
PID デュアル：ロール角 + ヨーレート
出力 クレストラダー補正
RAM 62%
Flash 56%
