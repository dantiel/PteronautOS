標準重量。熱収縮チューブ、コネクタ、筐体を取り除くと 30～60% 軽量化できます。

ESP32 ベースのレシーバー (ESP32-C3/S3) は異なるアーキテクチャのため未対応です。

主要スペック

MCU ESP8285 @ 80 MHz、1 MB フラッシュ
無線 ExpressLRS 2.4 GHz（SX1280）
ジャイロ I2C 上の MPU6050（GY-521）
サーボ 3 PWM チャンネル — 左翼、右翼、クレストラダー

配線

3 つのサーボチャンネルに加え、I2C バス上の MPU6050。完全なピン配置、I2C 配線、v1.0/v1.1 リビジョンの違いは PWMP7 ガイドにあります。
