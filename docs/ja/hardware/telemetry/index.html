テレメトリーとセンサー

VBAT、RSSI、リンク品質、ジャイロテレメトリーの無線機への返送 — 公開済みと予定。

VBAT

受信機は ADC ピン(PWMP7 の GPIO17)でバッテリー電圧をサンプリングし、CRSF テレメトリーで報告します。メインバッテリーから ADC パッドへ分圧回路を配線し、無線機が実際のパック電圧を読むように設定で分圧比を較正してください。

RSSIとリンク品質

RSSI とリンク品質は SX1280 から直接得られ、標準 ELRS テレメトリスロットで公開されます。距離判断には生 RSSI ではなく LQ(リンク品質)を使ってください。2.4 GHz ではより意味のある指標です。

ジャイロテレメトリー

Zephyrus AHRS はロール、ピッチ、ヨーレートをカスタムテレメトリーとしてストリーミングでき、飛行中にジャイロを調整したり後でフライトを再生したりできます。これは診断用テレメトリーです。プロダクションビルドではリンクをあふれさせないよう、高速経路から外してください。

予定センサー

  • 高度維持とグライド制御のための気圧計(BMP280)。
  • 自動グライドトリガーのための差圧センサーによる対気速度。
  • ライブ消費電力とパック持続時間のための電流センサー。
  • 位置ログとリターントゥホーム実験のための GPS。
