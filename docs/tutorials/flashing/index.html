Tutorial 01

Flashing PteronautOS

Build and install the hermetic firmware on the supported ESP8285 receiver target.

Before connecting power, remove propulsive loads from the wing mechanism and make sure no servo can drive into a hard stop. Flashing is electrical work; the airframe should remain mechanically safe throughout the procedure.

01 · Build the firmware

Clone the repository, install PlatformIO, and build the dedicated receiver environment. The target enables the PteronautOS identity, ornithopter control, and the ESP8285/SX1280 hardware configuration.

pio run -e PteronautOS_ESP8285_2400_RX

02 · Connect the receiver

Wire a 3.3 V FTDI adapter to the UART pads and connect ground first. Do not apply 5 V to the ESP8285 logic pins. Disconnect the MPU6050 where the board revision shares its pins with the programming header.

03 · Enter the bootloader

Hold BOOT while powering the receiver. ESP8285 auto-reset is not reliable on every board, so keep BOOT asserted until the flashing tool has established communication.

04 · Write the image

Replace the serial device below with the port used by your adapter, then write the generated firmware image with DOUT flash mode.

esptool.py --port /dev/cu.usbserial-XXXX --baud 115200 --before no_reset write_flash --flash_mode dout --flash_size 1MB --flash_freq 40m 0x0 firmware.bin

05 · Verify the installation

Power-cycle the receiver without holding BOOT. Confirm that its WiFi access point and WebUI become available (SSID: Pteronaut OS, password: flynatural), then load the configuration and verify the target name before reconnecting servos.

Continue with the Hardware page for pin maps and revision-specific wiring notes.
