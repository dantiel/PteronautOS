Tutorials

Getting PteronautOS into the air — from source to first flap, step by step.

01 · Build the firmware

Clone the repository and build the receiver target with PlatformIO.

pio run -e PteronautOS_ESP8285_2400_RX

02 · Flash the receiver

Wire an FTDI adapter to the UART pads, hold BOOT, and write the firmware image. On the ESP8285 the auto-reset line is unreliable, so keep BOOT held while powering the board.

esptool.py --port /dev/cu.usbserial-XXXX --baud 115200 --before no_reset write_flash --flash_mode dout --flash_size 1MB --flash_freq 40m 0x0 firmware.bin

03 · Bind your transmitter

Flash the same binding phrase on transmitter and receiver. The UID is derived from the phrase — same phrase on both ends, they find each other. The receiver status in the web UI shows the UID.

04 · Wire the servos

Three servo channels: left wing, right wing, and crest rudder. The MPU6050 gyro hangs on the I2C bus.

See the %a{href: "../hardware/"} Hardware page for pin maps and wiring.

05 · First flap

Power up, centre the trims, and advance the throttle. At zero ferocity the wings should beat in a clean sine. If a servo slams to an endstop, check the flapping centre offset and the servo pulse limits.

06 · Tune via the Web UI

Join the receiver's WiFi network and open the config panel in a browser. Adjust ferocity, glide angle, flapping centre offset, and rudder yaw/roll mixing — no reflash needed.

The full reference lives in the %a{href: "../documentation/"} Documentation page.
