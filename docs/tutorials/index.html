Tutorials

Practical guides for preparing the hardware, installing the hermetic firmware, and bringing a new PteronautOS airframe to life.

PteronautOS is not a conventional multirotor stack. It translates CRSF control into a coordinated wingbeat for two wing servos and a crest rudder, with Zephyrus stabilization remaining optional and gracefully degradable.

Start with the flashing guide below. Later guides will cover receiver wiring, binding, the first controlled flap, and tuning the waveform through the WebUI. Every procedure keeps the project’s core rules in view: deterministic timing, centred failsafe behaviour, and no blocking work in the flight loop.
