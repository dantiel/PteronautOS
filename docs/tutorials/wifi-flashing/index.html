Tutorial 08

Flashagem via WiFi com o Pteronaut-Egg

Flasheie e atualize inteiramente via WiFi — sem cabo, sem FTDI, sem UART, nunca.

O Pteronaut-Egg é um pequeno bootstrap WiFi (~294 KB) que vive no recetor. A sua única função é aceitar o firmware completo PteronautOS via WiFi e prepará-lo — assim, nunca precisas de nenhum cabo.

O ESP8285 tem uma única região flash de ~1 MB. Uma imagem completa (~636 KB) não cabe no seu próprio espaço livre de preparação, por isso não consegue atualizar-se via WiFi. O egg é suficientemente pequeno para caber, e a imagem completa é suficientemente pequena para reflashear o egg — fechando um ciclo infinito egg ↔ completo.

01 — Obtém o egg

Transfere a imagem pré-compilada do Pteronaut-Egg. É um bootstrap fixo e independente de configuração — sem definições, sem compilação.

Transferir pteronaut-egg.bin.gz

02 — Obtém o firmware completo

O firmware completo é sempre compilado de fresco no Fossil Etcher — escolhe o teu recetor, mixer e configuração e transfere a imagem mais recente diretamente do navegador. Sem PlatformIO.

Abrir o Fossil Etcher

O Etcher compila o PteronautOS atual a partir do código todas as vezes, para teres sempre o firmware mais recente com padrões de boa prática.

03 — Sem necessidade de flash

O teu recetor vem com o Pteronaut-Egg já instalado — não há nada para flashear e nunca é necessário um cabo. Se o egg for alguma vez apagado, podes restaurá-lo via WiFi a partir da WebUI do firmware completo.

04 — Liga-te ao egg

Liga o recetor. O egg abre um ponto de acesso WiFi; liga-te a ele e abre a página de upload do egg num navegador.

Campo Valor
Rede WiFi (AP) PTERONAUT-EGG
Palavra-passe WiFi hatchnatural
Página de upload (mDNS, com fallback 192.168.4.1) pteronaut-egg.local

05 — Carrega o firmware completo

Na página de upload do egg, arrasta o firmware completo que transferiste do Fossil Etcher para o egg ASCII. O egg prepara-o e reinicia no PteronautOS completo.

06 — Cada atualização futura

A partir de agora, atualizar são dois uploads WiFi e zero cabos. O PteronautOS completo executa a WebUI ELRS padrão — abre a sua página Firmware Update, carrega o egg de volta e depois carrega o novo firmware completo. O ciclo repete-se indefinidamente.

Risco de brick (honesto)

Como em qualquer flash por rádio: apenas uma imagem completa avariada cujo WiFi nunca arranca forçaria uma recuperação com fios. No uso normal, o egg remove o cabo por completo — sem cabo, nunca.

O Fossil Etcher é a ferramenta de flashagem partilhada para fluxos de trabalho WiFi e UART — transfere o egg ou compila o firmware completo diretamente, tudo a partir do navegador.
