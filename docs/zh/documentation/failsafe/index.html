失控保护行为

链路丢失时会发生什么——机翼中立、方向舵中立、优雅降级。

触发条件

当 CRSF 链路报告连接丢失，或通道数据陈旧超过配置的超时时间时，失控保护即会触发。遥控器自身的失控保护<em>并非</em>真相之源——PteronautOS 会重新施加自己的居中失控保护，因此无论遥控器品牌或绑定模式如何，行为都一致。

中立输出

触发时，每个舵机回到 <strong>1500&nbsp;µs</strong>，波形输出被抑制。机翼居中，冠舵居中。<code>voiceAileron/Elevator/Throttle/Rudder</code> 通道读数被重置，使 WebUI 状态轮询显示中性真值。

优雅降级

设计法则是<em>优雅降级</em>：发生故障的 MPU6050 绝不能使飞行器坠毁。Zephyrus 在陀螺仪故障时自行禁用，Ornithopter 混控器继续以纯摇杆输入飞行——失控保护路径与陀螺仪路径相互独立，因此一处故障绝不会级联到另一处。

恢复

恢复是自动的：当有效 CRSF 帧恢复时，混控器在下一个 tick 重新介入，舵机再次跟随实时通道。没有手动重置，也没有锁存——过渡只是回到指令位置的一次柔和斜坡。

飞行前先做台架测试。 该探索器描述的是指令数学波形，而非保证的舵机运动。在振幅、频率、连杆几何和舵机速度极限未经空载验证之前，请避免极端的不对称设置。
