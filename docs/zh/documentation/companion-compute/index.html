伴随计算模式

共生: PteronautOS 是精神, YOSHIMITSU 是手。两块板, 一次飞行 — 由一个管理员标志在桥的两侧分开。

架构

在伴随模式下, 两块 MCU 不再是接收器和转换器, 而成为拥有两半的一个大脑。此图即永恒地图:

陀螺仪为何留在 RP2040

MPU6050 在物理上连接到 RP2040 — 因此 PID 也在那里计算。把原始陀螺采样经桥发送到 PteronautOS, 只为了在那里做 PID 并回传修正, 纯属对延迟的献祭。握着陀螺仪的手纠正击打: Zephyrus 活在伴随板上, 而非接收机上。

划分

每一半都计算离自己最近的东西。

角色 板卡 职责
PTERONAUTOS ESP8285 CRSF RX 解码 + 混控意图(波形之魂) — 即稍早之前
YOSHIMITSU RP2040-Tiny 陀螺仪 + PID(Zephyrus, 本地) + 伴随计算 + PIO 舵机-PWM — 更接近肌肉记忆

两核, 两手

RP2040-Tiny 是唯一拥有硬件 PIO 状态机 — 共八个 — 以实现无毛刺舵机-PWM 的 ELRS-PWM 平台。它的两个 Cortex-M0+ 核心划分清晰:

  • Core1 · 伴随计算 — 混控 + 扑翼卸载: 手将划出的轨迹。
  • Core0 · 肌肉记忆 — PIO 舵机-PWM: 真正驱动翼与冠舵的采样。

管理员标志

一个编译期标志 — COMPANION_MODE — 决定 YOSHIMITSU 是保持沉默转换器, 还是作为伴随核心苏醒。关闭即是 KINCHO; 开启即是手。

为何是作弊码

没有其他 ELRS-PWM 板搭载带硬件 PIO 的双核。以这块小板的价格, 你得到两个核心 — 一个纯肌肉, 一个伴随计算机。在别处你要花更多, 却永远更弱。

更便宜, 且永远更强: 这是隐士忍者对市场的回答。

直升机或扑翼 — 同一击

从剑的视角看, 直升机或扑翼并无分别: 混控器发出规范轨迹 — 通道到舵机之路 — 而手从不问自己承载何种载具。背身而立 — 姿态继续飞行, 唯有目光变换。
