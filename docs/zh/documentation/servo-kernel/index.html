舵机内核

脉宽包络、按功能的微调与速度限制——低层舵机契约。

脉宽包络

伺服内核通过由 servoMinUs(默认 988)与 servoMaxUs(默认 2012)定义的全局包络，将归一化角度(−1…+1)映射为脉冲宽度。这取代了旧的编译期常量，使 0°/180° 行程无需重新构建即可适配任意舵机。数值被限制在 [500…1490] 与 [1510…2500]，并强制 min < max。

按功能的微调

servoTrimUs[] 是混合后应用的、按 ServoFunc 的校正(±300 µs)。它涵盖机翼对(索引 1/2)、方向舵(3)与后翼(8/9)。用它来归零单一舵面上半个齿的舵臂偏移——而不是去纠正机体不平衡，那属于混控器或陀螺仪的职责。

速度限制

舵机速度 限制每个 tick 的脉冲变化率，平滑剧烈反转并保护减速箱免受冲击载荷。它是对指令位置的低通，因此低值也会柔化扑翼反转——请依据行程上下端的 咔哒声 来调校。太慢则机翼滞后于波形；太快则冲击重新出现。

完整的脉冲/微调/速度参数列表与 JSON 键，请参阅固件中的伺服内核说明与 WebUI 参考。
