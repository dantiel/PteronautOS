硬件

PteronautOS 运行的板子及其接线方式。

支持的板子

板子 MCU · 无线电
Generic 2400 PWMP7 v1.0 ESP8285 · SX1280 2.4 GHz
Generic 2400 PWMP7 v1.1 ESP8285 · SX1280 2.4 GHz

关键规格

MCU ESP8285 @ 80 MHz，1 MB flash
无线电 ExpressLRS 2.4 GHz（SX1280）
陀螺仪 I2C 上的 MPU6050（GY-521）
舵机 3 个 PWM 通道 — 左机翼、右机翼、头冠方向舵

接线

三个舵机通道加上 I2C 总线上的 MPU6050。完整引脚图、I2C 接线和 v1.0/v1.1 版本差异见 PWMP7 指南。
