遥测与传感器

VBAT、RSSI、链路质量与陀螺仪遥测回传遥控——已暴露与计划内容。

VBAT

接收机在其 ADC 引脚(PWMP7 上的 GPIO17)采样电池电压，并通过 CRSF 遥测回报。请从主电池到 ADC 焊盘连接一个分压器；在配置中校准分压比，使遥控器读到真实的电池组电压。

RSSI与链路质量

RSSI 与链路质量直接来自 SX1280，并暴露在标准 ELRS 遥测槽位中。进行距离判断时请使用 LQ(链路质量)而非原始 RSSI——在 2.4 GHz 上它更有意义。

陀螺仪遥测

Zephyrus AHRS 可将横滚、俯仰与偏航速率作为自定义遥测流式传输，以便在飞行中调校陀螺仪或稍后回放飞行。这是诊断遥测——在生产构建中请让其远离快速路径，以免淹没链路。

规划中的传感器

  • 用于定高与滑翔控制的气压计(BMP280)。
  • 通过差压传感器获取空速，用于自动滑翔触发。
  • 用于实时功耗与电池组续航的电流传感器。
  • 用于位置记录与返航实验的 GPS。
