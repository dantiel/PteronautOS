教程

准备硬件、安装密封固件并让新 PteronautOS 机架运转起来的实用指南。

PteronautOS 并非传统的多旋翼协议栈。它将 CRSF 控制转换为两个机翼舵机与头冠方向舵的协调扑翼，西风稳定化保持可选并可优雅降级。

从下面的刷写指南开始。后续指南将涵盖接收机接线、对频、首次受控扑翼以及通过 WebUI 调校波形。每个步骤都遵循项目的核心规则：确定性时序、居中的失控保护行为，以及飞行循环中无阻塞工作。
