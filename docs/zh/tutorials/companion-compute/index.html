07

伴随计算模式

给剑一只手: 把 RP2040-Tiny 接成伴随核心。

你需要什么

  • Waveshare RP2040-Tiny — 手
  • MPU6050 陀螺仪(GY-521) — I2C
  • 三个舵机 — 翼 左/右、冠舵
  • 已烧录伴随桥的 PteronautOS 接收机

连接陀螺仪

MPU6050 直接连接到 RP2040 的 I2C — SDA 与 SCL — 而非接收机。陀螺仪属于手。

烧录两块板

照常刷写 PteronautOS，再为 RP2040-Tiny 刷写 YOSHIMITSU 草图。伴随之手通过 MUSHIN（無心）命令苏醒——一份固件，一卷轴。

武装 MUSHIN

MUSHIN（無心）默认武装开机——手先于思想出击。打开 USB 串口控制台，输入 MUSHIN 报告，MUSHIN ON/OFF 武装或解除。无需重刷：选择持久于闪存，MEDITATION 中的刷写桥不受任何影响。

验证

打开 USB 控制台, 阅读 JIGUANG 传说: 架势为 MEDITATION, 桥已立起, 而陀螺仪从手 — 而非接收机 — 报告。
