03

发射机配置

绑定ELRS遥控、映射四个控制通道并设置与舵机内核匹配的行程。

绑定

将接收机置于绑定模式(以配置的绑定口令供电，或使用 WebUI/按钮)，并在遥控器上启动 <strong>Bind</strong> 操作。默认绑定口令 <code>darographix</code> 产生固定 UID；绑定成功由常亮的链路 LED 以及 WebUI 状态轮询中的实时通道动作来确认。

通道映射

遥控通道 PteronautOS 角色
CH1 副翼(横滚)
CH2 升降舵(俯仰)
CH3 油门(扑翼驱动)
CH4 方向舵(偏航/冠)

按此顺序映射四个控制通道。PteronautOS 按 CRSF 顺序读取它们，因此请让 CH1–CH4 保持默认的 AETR 布局(若在配置中重排了它们，则与混控器的期望保持一致)。

行程与方向

将遥控输出设为 <strong>±100%</strong>(CRSF 172–1811&nbsp;µs，围绕 992&nbsp;µs 中心)。<em>不要</em>使用扩展限位——伺服内核已经映射完整的 988–2012&nbsp;µs 脉冲包络，裁剪遥控只会浪费分辨率。副微调必须保持为零；中立值按设计为 1500&nbsp;µs。

速率与指数曲线

从 <strong>100% 速率与 0% 指数</strong> 开始。扑翼权限主要由波形幅度而非摇杆行程决定，因此激进的遥控速率只会让飞行器变得神经质。一旦滑翔与扑翼良好，可添加温和的指数(15–25%)以获得更柔和的中位，仅在横滚响应过度指挥机翼时才降低速率。

验证

  • 摇杆打满右——右翼抬起，左翼落下。
  • 摇杆打满后(抬头)——两翼抬起机头。
  • 油门推高——扑翼频率升高；拉低——降低或滑翔。
  • 方向舵向右——冠向右偏转。
  • 关闭发射机——所有舵面居中(失控保护)。
