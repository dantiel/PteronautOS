教程 08

使用 Pteronaut-Egg 进行 WiFi 刷写

完全通过 WiFi 刷写和更新 — 无需线缆、无需 FTDI、无需 UART，永远不用。

Pteronaut-Egg 是驻留在接收机上的微型 WiFi 引导程序（约 294 KB）。它唯一的任务就是通过 WiFi 接收完整的 PteronautOS 固件并暂存 — 因此你完全不需要任何线缆。

ESP8285 只有一块约 1 MB 的闪存区域。完整镜像（约 636 KB）放不下它自身空闲的暂存空间，因此无法通过 WiFi 自我更新。Egg 足够小可以装入，而完整镜像也足够小可以刷回 Egg — 形成无限的 Egg ↔ 完整 循环。

01 — 获取 Egg

下载预编译的 Pteronaut-Egg 镜像。它是一个固定、与配置无关的引导程序 — 无需设置，无需构建。

下载 pteronaut-egg.bin.gz

02 — 获取完整固件

完整固件每次都在 Fossil Etcher 中全新构建 — 选择你的接收机、混控和配置，然后直接从浏览器下载最新镜像。无需 PlatformIO。

打开 Fossil Etcher

Etcher 每次都从源码构建当前的 PteronautOS，因此你总能获得带最佳实践默认值的最新固件。

03 — 无需刷写

你的接收机出厂时已预装 Pteronaut-Egg — 无需刷写任何内容，也永远不需要线缆。如果 Egg 被擦除，你可以从完整固件的 WebUI 通过 WiFi 恢复它。

04 — 连接到 Egg

给接收机通电。Egg 会打开一个 WiFi 热点；加入它，然后在浏览器中打开 Egg 的上传页面。

字段 值
WiFi 网络 (AP) PTERONAUT-EGG
WiFi 密码 hatchnatural
上传页面（mDNS，含 192.168.4.1 回退） pteronaut-egg.local

05 — 上传完整固件

在 Egg 的上传页面上，将从 Fossil Etcher 下载的完整固件拖到 ASCII Egg 上。Egg 会暂存它并重启进入完整的 PteronautOS。

06 — 之后的每次更新

从现在起，更新就是两次 WiFi 上传、零根线缆。完整的 PteronautOS 运行标准的 ELRS WebUI — 打开其 Firmware Update 页面，先上传回 Egg，再上传新的完整固件。此循环无限重复。

变砖风险（如实说明）

与任何无线刷写一样：只有 WiFi 完全无法启动的损坏完整镜像才会强制有线恢复。在正常使用中，Egg 彻底消除了线缆 — 无需线缆，永远不用。

Fossil Etcher 是 WiFi 与 UART 工作流共用的刷写工具 — 下载 Egg 或直接构建完整固件，全部在浏览器中完成。
