04

波形调校

用凶猛度、幅度、频率和滑翔角塑造扑翼行程，匹配你的机翼与机身。

在修改固件之前，请先用 烈度波形探索器 进行实时探索——同一模型驱动混控器。

凶猛度（行程不对称）

<strong>烈度</strong> 是行程/回程的不对称性。在 <code>0</code> 时波形为纯正弦——上下时间相等。提高下扑烈度使下行程更快、上行程驻留更长(上扑烈度则反之)。这改变了推力产生的<em>位置</em>：快速下扑 + 缓慢回程模仿真实鸟类的动力行程，是最有效的手感变化。

从 <code>down&nbsp;8, up&nbsp;0</code> 开始以获得有力的下扑，然后小步混入上扑烈度。过大的不对称会让机翼在反转时“啪”地骤断——可闻为咔哒声，可见为舵机发热。

幅度与频率

幅度并非直接设定；它由<strong>频率</strong>与<strong>行程速度</strong>涌现而来。在给定速度下提高扑翼频率会缩短行程，降低则加长行程。内核会封顶幅度，使舵机绝不离开 988–2012&nbsp;µs 包络。请将频率调至机体的自然扑翼共振——频率过高浪费能量，过低则跌至有效升力之下。

<strong>形状混合</strong> 滑块将纯正弦向梯形混合(在反转点驻留更长)。混合越高 = 反转越干脆、两端推力越大；混合越低 = 巡航越平滑、越高效。

滑翔与扑翼角度

<strong>滑翔角</strong> 与 <strong>扑翼角</strong> 都是<em>中心偏移</em>(int8, ±15°)，而非幅度。滑翔在油门指令滑翔时设置公共机翼角度；扑翼则移动扑翼行程的中心。它们让你在不触碰机械连杆的情况下，为低速飞行与快速巡航偏置机翼。

起始预设

预设 下 / 上 混合 特性
极限 8 / 0 100% 强力动力行程，激进
近正弦 7 / 1 100% 均衡，最自然
高驻留 8 / 6 100% 长反转驻留，漂浮
混合 8 / 6 50% 柔和混合，巡航效率

从 <strong>近正弦</strong> 开始，确认飞行稳定后，仅当你想要冲击力时才向 <strong>极限</strong> 推进。每个机体都有不同的甜蜜点——一次只更改一个参数。
