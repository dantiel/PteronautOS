Fossil Etcher

Firmware direkt im Browser bauen und flashen — keine Konsole, kein PlatformIO.

Build-Konfiguration

Erweitert — I2C, Mushin, WiFi

MUSHIN verlagert Servos + Gyro auf den RP2040 — kein lokales PWM, kein lokaler Gyro auf dieser Platine.

Prüft SCL vor der I2C-Initialisierung, damit ein fehlender MPU6050 sauber bootet. Bei ungewöhnlichen Pull-ups deaktivieren.

Gyro ist aus — aktiviere Zephyrus, um das MPU6050 zu nutzen. Lokales Gyro nur auf der PWMP7-Platine.

System & WebUI
WebUI-Sprachen

Sprachen für die WebUI auswählen — keine Auswahl bäckt alle 11 ein.

Web Serial wird in Safari/Firefox nicht unterstützt. Erstelle die Firmware, lade die .bin herunter und flashe sie mit esptool — oder öffne diese Seite in Chrome/Edge/Opera zum Flashen per USB.

Der Build erzeugt eine einzelne zusammengeführte .bin in GitHub Actions (~3–4 min).

Firmware-Fossilien

Jeder Cloud-Build wird hier als Firmware-Fossil mit Einstellungen und Datum aufbewahrt. Klicken zum Laden, × zum Verwerfen.
