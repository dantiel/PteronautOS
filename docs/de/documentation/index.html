Konzepte

Ferocity
Asymmetrie zwischen Schlag und Rücklauf sowie Verweildauer — 0 ist ein reiner Sinus.
Wellenform
Die Flügelschlagkurve; die Amplitude ergibt sich aus Grad/s ÷ 2·Frequenz.
Gleitwinkel
Flügelmittelpunkt-Versatz für den Gleitflug.
Flatter-Mittelpunkt-Versatz
Mittelpunkt-Vorspannung während des Flügelschlags (−15…+15 Grad).
Rudermischung
Gier-/Roll-Mischung, die das Kammruder antreibt.
Gas-Ferocity-Mischung
Wie stark das Gas in die Ferocity einkoppelt.
Failsafe
Die Flügel kehren in die Neutralstellung zurück, wenn die Verbindung abbricht.

Geometrie der Ferocity-Wellenform

Ferocity steuert sowohl den Charakter als auch das Timing eines Halbschlags. Intern wird die 0–100-Einstellung der WebUI auf 0–8 abgebildet. Höhere Abschlag-Ferocity verkürzt den Abschlagsanteil des Zyklus; höhere Rücklauf-Ferocity verkürzt den Rücklaufanteil. Die verbleibende Zeit wird auf die gegenüberliegende Hälfte übertragen — es gibt keine Pause bei null.

Die profilbezogene Ferocity-Shape-Steuerung wählt den Hoch-Ferocity-Charakter. Bei 0 % bevorzugt sie eine endliche Plateau-/Rechteckform. Bei 100 % bevorzugt sie einen abgerundeten pyramidalen Verlauf. Jede Hälfte nutzt weiterhin ihre eigene Ferocity, sodass eine Hälfte mit niedriger Ferocity gestreckt und sinusförmig bleibt, während eine Hälfte mit hoher Ferocity sich einer direkten diagonalen Traverse nähert.

Extreme Kombinationen lesen

Eine 7 / 1-Kombination erzeugt klar einen kurzen, spitzen Abschlag und einen langen sinusförmigen Rücklauf. Exakte und nahezu maximale Werte erfordern Sorgfalt: Das aktuelle Dauergesetz nutzt den unter Ferocity 8 verbleibenden Betrag. Folglich weist 8 / 0 dem Abschlag nur etwa 0,125 % des Zyklus zu, während selbst 8 / 6 etwa 0,5 % zuweist. Die Position bleibt kontinuierlich, aber die angeforderte Geschwindigkeit und Beschleunigung können physikalisch unerreichbar werden.

Vor dem Flug auf dem Prüfstand testen. Der Explorer beschreibt die kommandierte mathematische Wellenform, keine garantierte Servobewegung. Vermeiden Sie extreme asymmetrische Einstellungen, bis Amplitude, Frequenz, Gestängegeometrie und Servo-Geschwindigkeitsgrenzen ohne aerodynamische Last verifiziert wurden.
