PTERONAUTOS ट्यूटोरियल हार्डवेयर दस्तावेज़

ट्यूटोरियल 01

PteronautOS फ्लैश करना

CYCLONE ELRS 2.4GHz 7CH PWM RX रिसीवर को उदाहरण मानकर हर्मेटिक फ़र्मवेयर बनाएँ और स्थापित करें।

PteronautOS अन्य रिसीवर बोर्ड का भी समर्थन करता है। ESP8285 साझा करने से उनकी वायरिंग एक जैसी नहीं हो जाती: खुले GPIO, चैनल आवंटन, प्रोग्रामिंग कनेक्शन और PCB संशोधन भिन्न हो सकते हैं। नीचे की पावर और CH2/CH3 वायरिंग इस CYCLONE उदाहरण पर लागू होती है; दूसरा रिसीवर जोड़ने से पहले अपने बोर्ड का पिनआउट और समर्थित हार्डवेयर विन्यास जाँचें।

पावर जोड़ने से पहले, विंग तंत्र से प्रणोदक भार हटाएँ और सुनिश्चित करें कि कोई सर्वो कठोर स्टॉप पर न टकराए। फ्लैशिंग विद्युत कार्य है; पूरी प्रक्रिया के दौरान एयरफ़्रेम यांत्रिक रूप से सुरक्षित रहना चाहिए।

01 · फ़र्मवेयर बनाएँ

रिपॉज़िटरी क्लोन करें, PlatformIO स्थापित करें, और रिपॉज़िटरी रूट से निम्न कमांड चलाएँ। PlatformIO प्रोजेक्ट src में है; यह कमांड इस उदाहरण में प्रयुक्त समर्पित ESP8285 रिसीवर वातावरण बनाती है।

pio run -d src -e PteronautOS_ESP8285_2400_RX

02 · रिसीवर कनेक्ट करें

इस CYCLONE रिसीवर के लिए, रिसीवर आपूर्ति हेतु FTDI अडैप्टर के 5V पावर आउटपुट का उपयोग करें, न कि उसके 3.3V आउटपुट का। इसके UART कनेक्शन चैनल 2 और 3 के सिग्नल पिन पर हैं — अलग UART पैड खोजने की आवश्यकता नहीं है।

FTDI अडैप्टर रिसीवर कनेक्शन
GND GND (−)
5 V / VCC आपूर्ति (+)
TX CH3 सिग्नल — रिसीवर RX (GPIO3)
RX CH2 सिग्नल — रिसीवर TX (GPIO1)

5V सेटिंग रिसीवर पावर को दर्शाती है। अपने अडैप्टर का दस्तावेज़ देखें: आपूर्ति आउटपुट 5V होने पर भी TX/RX को ESP8285-संगत 3.3V लॉजिक का उपयोग करना चाहिए। एक साथ दूसरी पावर आपूर्ति न जोड़ें।

03 · बूटलोडर में प्रवेश करें

BOOT (GPIO0) दबाए रखें, FTDI USB केबल निकालकर फिर जोड़ें, BOOT को लगभग एक सेकंड दबाए रखें, फिर छोड़ दें। फ्लैशिंग स्क्रिप्ट स्वचालित रीसेट नहीं करती, इसलिए चलाने से पहले मैन्युअल रूप से बूटलोडर में प्रवेश करें।

04 · इमेज लिखें

रिपॉज़िटरी रूट से, दी गई फ्लैशिंग स्क्रिप्ट चलाएँ। यह PlatformIO-बंडल्ड फ्लैशिंग टूल और बने फ़र्मवेयर को खोजती है, एक सीरियल पोर्ट चुनती है, और आवश्यक फ्लैश सेटिंग्स के साथ इमेज लिखती है।

./scripts/flash.sh

स्वचालित पोर्ट चयन macOS /dev/cu.* डिवाइस खोजता है। यदि कई सीरियल डिवाइस जुड़े हों, या आप भिन्न ऑपरेटिंग सिस्टम उपयोग कर रहे हों, तो रिसीवर अडैप्टर का पोर्ट स्पष्ट रूप से चुनें। नीचे के उदाहरण को अपने वास्तविक डिवाइस पथ से बदलें।

./scripts/flash.sh --port /dev/cu.usbserial-XXXX

फ़र्मवेयर लिखे बिना बूटलोडर संचार जाँचने के लिए वैकल्पिक चेक मोड का उपयोग करें। विफल होने पर, पुनः प्रयास से पहले BOOT पावर साइकिल दोहराएँ।

./scripts/flash.sh --port /dev/cu.usbserial-XXXX --check

05 · स्थापना सत्यापित करें

BOOT दबाए बिना रिसीवर को पावर-साइकिल करें। पुष्टि करें कि उसका WiFi एक्सेस पॉइंट और WebUI उपलब्ध हो गए हैं (SSID: Pteronaut OS , पासवर्ड: flynatural ), फिर कॉन्फ़िगरेशन लोड करें और सर्वो दोबारा जोड़ने से पहले टारगेट नाम सत्यापित करें।

आगे पढ़ें हार्डवेयर पृष्ठ पिन मैप और संशोधन-विशिष्ट वायरिंग नोट्स के लिए।
