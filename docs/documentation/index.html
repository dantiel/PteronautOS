Concepts

Ferocity
Stroke/return asymmetry and dwell — 0 is a pure sine.
Waveform
The wingbeat curve; amplitude comes from deg/s ÷ 2·freq.
Glide angle
Wing centre offset for gliding flight.
Flapping centre offset
Centre bias during the flap stroke (−15…+15 deg).
Rudder mixing
Yaw/roll blend that drives the crest rudder.
Throttle ferocity mix
How much throttle couples into ferocity.
Failsafe
Wings return to neutral if the link drops.
