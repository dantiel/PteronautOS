Hardware

The boards PteronautOS runs on, and how to wire them.

Supported boards

Board MCU · Radio
Generic 2400 PWMP7 v1.0 ESP8285 · SX1280 2.4 GHz
Generic 2400 PWMP7 v1.1 ESP8285 · SX1280 2.4 GHz

Key specs

MCU ESP8285 @ 80 MHz, 1 MB flash
Radio ExpressLRS 2.4 GHz (SX1280)
Gyro MPU6050 (GY-521) on I2C
Servos 3 PWM channels — left wing, right wing, crest rudder

Wiring

Three servo channels plus the MPU6050 on the I2C bus. The full pin map, I2C wiring, and v1.0/v1.1 revision differences are in the PWMP7 guide.
