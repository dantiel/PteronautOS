Convertidor CRSF→PWM

Convierte una placa ESP32-S3 de $6 en un convertidor CRSF-servo autónomo — la forma más barata de volar PteronautOS en un receptor sin PWM nativo.

¿Por qué un convertidor?

Most ExpressLRS receivers — HappyModel EP2, EP1, EPW6 in CRSF mode — expose only a serial CRSF stream and no usable PWM headers. PteronautOS expects three servo channels (left wing, right wing, crest rudder). The cleanest, cheapest bridge is a tiny ESP32-S3 board programmed as a pure CRSF→PWM converter: it reads the CRSF frames over UART and fans out rock-steady servo pulses.

The Waveshare ESP32-S3-Tiny (~6 USD) is ideal: it is 23 × 18 mm, weighs under 3 g without headers, runs at up to 240 MHz, and — unlike the ESP8266 — every GPIO is a true PWM-capable pin. A single board can generate up to 8 servo channels.

CRSF runs at 420 000 baud (ELRS) — do not use the default 115 200. Servos connect to any three free GPIOs, e.g. GPIO1 (left wing), GPIO2 (right wing), GPIO3 (rudder), each with its own signal line; servo 5V and GND come from a shared BEC rail.

Flashear el firmware

Flash the converter with a minimal Arduino sketch. The core loop is a CRSF parser that maps the first four channels (roll, pitch, throttle, yaw) to 988–2012 µs servo pulses: 

#include 

Servo wingL, wingR, rudder;
#define CRSF_BAUD 420000
#define CRSF_MAX_CH 16
uint16_t channels[CRSF_MAX_CH];

void setup() {
  Serial.begin(CRSF_BAUD, SERIAL_8N1);
  wingL.attach(1); wingR.attach(2); rudder.attach(3);
  wingL.writeMicroseconds(1500);
  wingR.writeMicroseconds(1500);
  rudder.writeMicroseconds(1500);
}

void loop() {
  if (Serial.available() >= 26) {
    uint8_t hdr = Serial.read();
    if (hdr == 0xC8 || hdr == 0xEE) {          // device / extended
      uint8_t len = Serial.read();
      uint8_t type = Serial.read();
      if (type == 0x16) {                       // RC channels
        uint8_t payload[22];
        Serial.readBytes(payload, 22);
        for (int i = 0; i < 16; i++) {
          channels[i] = (payload[i*11/8] | payload[i*11/8+1]<<8)
                        & 0x07FF;
        }
        wingR.writeMicroseconds(map(channels[0],172,1811,988,2012));
        rudder.writeMicroseconds(map(channels[1],172,1811,988,2012));
        wingL.writeMicroseconds(map(channels[2],172,1811,988,2012));
      }
    }
  }
}

A production-ready version validates the CRC, frames the stream on the 26-byte packet boundary and keeps a failsafe (if no valid frame arrives within 1 s, hold the last known pulses or centre to 1500 µs). PteronautOS itself already implements a centred failsafe on the RX — but a standalone converter should be fail-safe on its own.

A ready-to-compile, CRC-checked implementation with failsafe and up to eight channels lives in the repository as sketches/esp32s3_yoshimitsu/esp32s3_yoshimitsu.ino. If you also want to flash EP2-class receivers without an FTDI adapter, the same S3 board can become a pocket flasher — see Tutorial 07 — ESP32-S3 Toolbox.

Verificación

  • Power the RX and the ESP32-S3 from the same 5V rail.
  • On the radio, bind and wiggle each stick; the servos must track smoothly with no jitter.
  • Verify the failsafe: switch the transmitter off — servos must return to 1500 µs.
  • If pulses are stuck or twitchy, confirm the baud is 420 000 and GND is shared.
