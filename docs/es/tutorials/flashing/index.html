Tutorial 01

Flashing de PteronautOS

Compila e instala el firmware hermético usando un receptor CYCLONE ELRS 2.4GHz 7CH PWM RX como ejemplo.

Compila y graba el firmware directo desde el navegador — sin toolchain ni drivers. Chrome, Edge y Opera graban por USB; los demás navegadores descargan el .bin.

Flashear en línea

PteronautOS también admite otras placas receptoras. Compartir un ESP8285 no hace idéntico su cableado: los GPIO expuestos, la asignación de canales, las conexiones de programación y las revisiones de PCB pueden diferir. La alimentación y el cableado CH2/CH3 de abajo se aplican a este ejemplo CYCLONE; comprueba el pinout de tu placa y la configuración de hardware soportada antes de conectar otro receptor.

Antes de conectar la alimentación, retira las cargas propulsivas del mecanismo del ala y asegúrate de que ningún servo pueda chocar contra un tope duro. El flasheo es trabajo eléctrico; la célula debe permanecer mecánicamente segura durante todo el procedimiento.

01 · Compila el firmware

Primero compila la WebUI — la interfaz que se integra en el firmware del receptor. Este paso requiere Node.js 20 o superior y npm. La bandera I18N_LOCALES selecciona los idiomas que se compilan; el ejemplo de abajo integra el idioma de este tutorial más el inglés. Omite la bandera para incluir los 11 idiomas.

cd src/html && nvm use 20 && I18N_LOCALES=es,en npm run build:pteronautos

Clona el repositorio, instala PlatformIO y ejecuta el siguiente comando desde la raíz del repositorio. El proyecto PlatformIO está en src; este comando compila el entorno dedicado del receptor ESP8285 usado en este ejemplo.

cd ../.. && pio run -d src -e PteronautOS_ESP8285_2400_RX

02 · Conecta el receptor

Para este receptor CYCLONE, usa la salida de 5 V del adaptador FTDI para la alimentación del receptor, no su salida de 3,3 V. Sus conexiones UART están en los pines de señal de los canales 2 y 3 — no hace falta localizar pads UART separados.

Adaptador FTDI Conexión del receptor
GND GND (−)
5 V / VCC Alimentación (+)
TX Señal CH3 — RX del receptor (GPIO3)
RX Señal CH2 — TX del receptor (GPIO1)

El ajuste de 5 V se refiere a la alimentación del receptor. Consulta la documentación de tu adaptador: TX/RX deben usar lógica de 3,3 V compatible con ESP8285, incluso cuando la salida de alimentación es de 5 V. No conectes una segunda fuente de alimentación al mismo tiempo.

03 · Entra en el bootloader

Mantén BOOT (GPIO0) pulsado, desconecta y vuelve a conectar el cable USB del FTDI, mantén BOOT pulsado alrededor de un segundo y suéltalo. El script de flasheo no realiza un reinicio automático, así que entra en el bootloader manualmente antes de ejecutarlo.

04 · Escribe la imagen

Desde la raíz del repositorio, ejecuta el script de flasheo proporcionado. Compila la WebUI y el firmware con el idioma que elijas, localiza una herramienta de flasheo incluida con PlatformIO y el firmware compilado, selecciona un puerto serie y escribe la imagen con los ajustes de flash necesarios.

La bandera --lang de abajo integra directamente el idioma de este tutorial. Omítela para elegir de forma interactiva: todos los idiomas, una selección o saltarte la recompilación.

./scripts/flash.sh --lang es

La selección automática de puerto busca dispositivos macOS /dev/cu.*. Si hay varios dispositivos serie conectados, o usas un sistema operativo diferente, selecciona explícitamente el puerto del adaptador del receptor. Sustituye el ejemplo de abajo por la ruta real de tu dispositivo.

./scripts/flash.sh --lang es --port /dev/cu.usbserial-XXXX

Para comprobar la comunicación con el bootloader sin escribir firmware, usa el modo de verificación opcional. Si falla, repite el ciclo de encendido de BOOT antes de volver a intentarlo.

./scripts/flash.sh --port /dev/cu.usbserial-XXXX --check

05 · Verifica la instalación

Reinicia el receptor sin mantener BOOT pulsado. Confirma que su punto de acceso WiFi y la WebUI están disponibles (SSID: Pteronaut OS , contraseña: flynatural ), luego carga la configuración y verifica el nombre del target antes de volver a conectar los servos.
