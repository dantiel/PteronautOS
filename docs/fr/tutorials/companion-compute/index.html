07

Mode Companion Compute

Donne une main à l'épée : câble le RP2040-Tiny comme cœur companion.

Ce qu'il te faut

  • Waveshare RP2040-Tiny — la main
  • Gyroscope MPU6050 (GY-521) — I2C
  • trois servos — aile G/D, gouvernail de crête
  • Récepteur PteronautOS, flashé avec le pont companion

Câble le gyroscope

Le MPU6050 se connecte directement à l'I2C du RP2040 — SDA et SCL — et non au récepteur. Le gyroscope appartient à la main.

Flashe les deux cartes

Flashe PteronautOS normalement, puis le sketch YOSHIMITSU pour le RP2040-Tiny. La main compagne s'éveille par la commande MUSHIN (無心) — un firmware, un parchemin.

Armer MUSHIN

MUSHIN (無心) démarre armé par défaut — la main frappe avant la pensée. Ouvre la console USB et tape MUSHIN pour un rapport, MUSHIN ON/OFF pour armer ou désarmer. Pas de reflash : le choix persiste en flash et le pont flasheur en MEDITATION n'est jamais touché.

Vérifie

Ouvre la console USB et lis la légende JIGUANG : la posture est MEDITATION, le pont est levé, et le gyroscope rapporte depuis la main — pas depuis le récepteur.
