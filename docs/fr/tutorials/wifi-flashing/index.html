Tutoriel 08

Flashage WiFi avec le Pteronaut-Egg

Flashez et mettez à jour entièrement en WiFi — aucun câble, aucun FTDI, aucun UART, jamais.

Le Pteronaut-Egg est un petit bootstrap WiFi (~294 Ko) qui vit sur le récepteur. Son seul rôle est d’accepter le firmware complet PteronautOS en WiFi et de le mettre en place — vous n’avez donc jamais besoin de câble.

L’ESP8285 possède une seule région flash de ~1 Mo. Une image complète (~636 Ko) ne tient pas dans son propre espace libre de préparation, elle ne peut donc pas se mettre à jour en WiFi. L’egg est assez petit pour tenir, et l’image complète est assez petite pour reflasher l’egg — bouclant un cycle infini egg ↔ complet.

01 — Obtenez l’egg

Téléchargez l’image Pteronaut-Egg précompilée. C’est un bootstrap fixe et indépendant de la configuration — aucun réglage, aucune compilation requise.

Télécharger PTERONAUT-EGG.BIN.gz

02 — Flasher l'œuf (première fois)

Votre récepteur est livré avec ExpressLRS d'origine — pas l'œuf. Installez l'œuf une fois, entièrement en WiFi, via la propre WebUI du récepteur. Aucun câble, jamais.

Alimentez le récepteur. ExpressLRS d'origine ouvre un point d'accès WiFi. Rejoignez-le avec les identifiants ExpressLRS par défaut ci-dessous, puis ouvrez la WebUI.

Champ Valeur
Réseau WiFi (AP) ExpressLRS RX
Mot de passe WiFi expresslrs
Page de téléversement WebUI → Firmware Update

Décompressez le PTERONAUT-EGG.BIN.gz téléchargé, puis téléversez le PTERONAUT-EGG.BIN sur la page Firmware Update et attendez que le récepteur redémarre dans l'œuf.

03 — Obtenir le firmware complet

Le firmware complet est toujours compilé fraîchement dans le Fossil Etcher — choisissez votre récepteur, mixer et configuration, puis téléchargez l’image la plus récente directement depuis le navigateur. Pas de PlatformIO.

Ouvrir le Fossil Etcher

L’Etcher compile le PteronautOS actuel depuis le code à chaque fois, vous obtenez donc toujours le dernier firmware avec des réglages par défaut de bonne pratique.

04 — Se connecter à l'œuf

Alimentez le récepteur. L'œuf ouvre un point d'accès WiFi ; rejoignez-le avec les identifiants ci-dessous, puis ouvrez la page de téléversement dans un navigateur (pteronaut-egg.local, ou 192.168.4.1 en secours).

Champ Valeur
Réseau WiFi (AP) PTERONAUT-EGG
Mot de passe WiFi hatchnatural
Page de téléversement pteronaut-egg.local

05 — Téléverser le firmware complet

Sur la page de téléversement de l’egg, faites glisser le firmware complet téléchargé depuis le Fossil Etcher sur l’egg ASCII. L’egg le prépare et redémarre dans le PteronautOS complet.

06 — Chaque mise à jour future

Désormais, mettre à jour se fait en deux téléversements WiFi et zéro câble. Le PteronautOS complet exécute la WebUI ELRS standard — ouvrez sa page Firmware Update, téléversez l’egg en retour, puis téléversez le nouveau firmware complet. Le cycle se répète indéfiniment.

Réseaux WiFi comparés

Chaque étape utilise son propre réseau WiFi et mot de passe, et une page de téléversement différente. Voici la carte complète :

Étape Réseau WiFi (AP) Mot de passe Page de téléversement
ExpressLRS d'origine (livré sur le récepteur) ExpressLRS RX expresslrs WebUI → Firmware Update
Pteronaut-Egg PTERONAUT-EGG hatchnatural pteronaut-egg.local
PteronautOS complet Pteronaut OS flynatural WebUI → Firmware Update

Risque de brick (honnête)

Comme tout flashage en l’air : seule une image complète cassée dont le WiFi ne démarre jamais forcerait une récupération filaire. En usage normal, l’egg supprime entièrement le câble — aucun câble, jamais.

Le Fossil Etcher est l’outil de flashage partagé pour les flux WiFi et UART — compile le firmware complet ou flashe par Web Serial, le tout depuis le navigateur. Sans PlatformIO.
