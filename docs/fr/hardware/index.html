Caractéristiques clés

MCU ESP8285 @ 80 MHz, 1 Mo flash
Radio ExpressLRS 2,4 GHz (SX1280)
Gyroscope MPU6050 (GY-521) en I2C
Servos 3 canaux PWM — aile gauche, aile droite, gouvernail de crête

Câblage

Trois canaux de servo plus le MPU6050 sur le bus I2C. Le brochage complet, le câblage I2C et les différences entre révisions v1.0/v1.1 figurent dans le guide PWMP7.
