Récepteurs compatibles

Tout récepteur ExpressLRS 2,4 GHz basé sur ESP8285 + SX1280/SX1281 avec sorties PWM — ou un récepteur CRSF associé à un convertisseur CRSF→PWM — peut exécuter PteronautOS. Les prix sont approximatifs et varient selon la région.

Les récepteurs basés sur ESP32 (ESP32-C3/S3) utilisent une architecture différente et ne sont pas encore pris en charge.

Caractéristiques clés

MCU ESP8285 @ 80 MHz, 1 Mo flash
Radio ExpressLRS 2,4 GHz (SX1280)
Gyroscope MPU6050 (GY-521) en I2C
Servos 3 canaux PWM — aile gauche, aile droite, gouvernail de crête

Câblage

Trois canaux de servo plus le MPU6050 sur le bus I2C. Le brochage complet, le câblage I2C et les différences entre révisions v1.0/v1.1 figurent dans le guide PWMP7.
