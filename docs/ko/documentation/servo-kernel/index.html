서보 커널

펄스 폭 범위, 기능별 트림, 속도 제한 — 저수준 서보 계약.

펄스 폭 범위

서보 커널은 servoMinUs(기본 988)와 servoMaxUs(기본 2012)로 정의되는 전역 엔벨로프를 통해 정규화된 각도(−1…+1)를 펄스 폭으로 매핑합니다. 이는 기존 컴파일 타임 상수를 대체하여 0°/180° 스윙을 재빌드 없이 어떤 서보에도 맞출 수 있게 합니다. 값은 [500…1490] 및 [1510…2500]으로 제한되며 min < max가 강제됩니다.

기능별 트림

servoTrimUs[]는 믹싱 후 적용되는 ServoFunc별 보정(±300 µs)입니다. 날개 쌍(인덱스 1/2), 러더(3), 뒷날개(8/9)를 담당합니다. 단일 표면의 반 톱니 혼 오프셋을 영점화하는 데 사용하세요. 기체 불균형을 바로잡는 용도가 아니며, 그것은 믹서나 자이로의 몫입니다.

속도 제한

서보 속도는 틱당 펄스 변화율을 제한하여 급격한 반전을 부드럽게 하고 기어박스를 충격 하중으로부터 보호합니다. 명령 위치에 대한 저역 통과이므로 낮은 값은 플랩 반전도 부드럽게 합니다. 스트로크 상·하단의 클릭에 맞춰 조정하세요. 너무 느리면 날개가 파형에 뒤처지고, 너무 빠르면 충격이 다시 나타납니다.

전체 펄스/트림/속도 매개변수 목록과 JSON 키는 펌웨어의 서보 커널 노트와 WebUI 참조를 확인하세요.
