페일세이프 동작

링크가 끊기면 — 날개 중립, 러더 중립, 우아한 성능 저하.

트리거 조건

CRSF 링크가 연결 손실을 보고하거나 채널 데이터가 설정된 타임아웃을 넘어 오래되면 페일세이프가 작동합니다. 라디오 자체 페일세이프는 <em>진실의 원천이 아닙니다</em>. PteronautOS가 자체 중앙 페일세이프를 다시 부과하므로 라디오 브랜드나 바인드 모드와 무관하게 동작이 동일합니다.

중립 출력

트리거되면 모든 서보가 <strong>1500&nbsp;µs</strong>로 복귀하고 파형 출력이 억제됩니다. 날개가 중앙에 오고 크레스트 러더가 중앙에 옵니다. <code>voiceAileron/Elevator/Throttle/Rudder</code> 채널 판독값이 리셋되어 WebUI 상태 폴이 중립 진실을 표시합니다.

우아한 성능 저하

설계 규칙은 <em>저하 속의 우아함</em>입니다. MPU6050 고장이 기체를 추락시켜서는 안 됩니다. Zephyrus는 자이로 고장 시 스스로 비활성화하고 Ornithopter 믹서는 순수 스틱 입력으로 계속 비행합니다. 페일세이프 경로와 자이로 경로가 독립적이므로 한쪽 고장이 다른 쪽으로 연쇄되지 않습니다.

복구

복구는 자동입니다. 유효한 CRSF 프레임이 재개되면 믹서가 다음 틱에 다시 관여하고 서보가 라이브 채널을 다시 따릅니다. 수동 리셋이나 래칭은 없습니다. 전환은 명령 위치로 돌아가는 단일 소프트 램프입니다.

비행 전 벤치 테스트. 익스플로러는 보장된 서보 움직임이 아니라 명령된 수학적 파형을 설명합니다. 진폭, 주파수, 링키지 기하, 서보 속도 한계가 공기역학적 부하 없이 검증될 때까지 극단적인 비대칭 설정을 피하세요.
