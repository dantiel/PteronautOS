제피로스 자이로 배선

MPU6050을 I2C 버스에 연결하고 핀 충돌을 해결하고 시리얼 로그로 AHRS를 검증하세요.

I2C 핀 선택

Zephyrus 기본 I2C 핀은 GPIO4 (SDA)와 GPIO5 (SCL)입니다. PWMP7 v1.0에서는 괜찮습니다. v1.1에서는 GPIO2/GPIO5가 노출되지 않아 Zephyrus가 GPIO1 (SDA, CH2)와 GPIO3 (SCL, CH3)를 사용합니다. 항상 실크스크린을 핀 맵과 대조하세요. GPIO4는 SX1280 라디오 인터럽트용으로 하드 예약되어 있어 절대 다른 용도로 쓰면 안 됩니다.

GY-521 배선

GY-521 수신기
VCC 5V 레일(온보드 레귤레이터가 3.3V 생성)
GND GND
SDA GPIO1 (CH2) — v1.0에서는 GPIO5
SCL GPIO3 (CH3) — v1.0에서는 GPIO2
AD0 / INT / XDA / XCL 열어 둠

GY-521은 자체 4.7 kΩ 풀업과 AMS1117-3.3V 레귤레이터를 갖췄습니다. 5V를 공급하면 자체 3.3V를 만들고 로직 레벨이 자동으로 맞습니다. 총 네 가닥, 트레이스 절단 없음, 추가 레귤레이터 없음.

캘리브레이션과 검증

Mahony AHRS는 부팅 시 자이로 바이어스를 자체 보정합니다. 전원 인가 후 1초 동안 기체를 가만히 두세요. 시리얼 로그로 센서 생존을 확인하세요. 기울이면 피치/롤이 기체를 따라가야 하고, 크레스트 러더는 수동 롤에 반대 작용해야 합니다(오른쪽 롤 → 러더 왼쪽 보정). 부팅 시 버스가 멈추면 예약된 핀에 잘못 연결된 것입니다. 맵을 다시 확인하고 올바른 CH2/CH3 쌍으로 옮기세요.
