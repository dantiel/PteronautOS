컴패니언 컴퓨트 모드

칼에 근육을 주세요: RP2040-Tiny를 컴패니언 코어로 배선하세요.

필요한 것

  • Waveshare RP2040-Tiny — 근육
  • MPU6050 자이로(GY-521) — I2C
  • 서보 셋 — 날개 좌/우, 볏 방향타
  • 컴패니언 브리지로 플래시된 PteronautOS 수신기

자이로 배선

MPU6050은 수신기가 아니라 RP2040의 I2C — SDA와 SCL — 에 직접 연결됩니다. 자이로는 근육에 속합니다.

두 보드 플래시

PteronautOS를 평소처럼 플래시한 뒤 RP2040-Tiny용 YOSHIMITSU 스케치를 플래시하세요. 동반의 근육은 MUSHIN(無心) 명령으로 깨어납니다 — 하나의 펌웨어, 하나의 두루마리.

MUSHIN 무장하기

MUSHIN(無心)은 기본으로 무장한 채 부팅합니다 — 근육이 생각보다 먼저 칩니다. USB 콘솔을 열고 MUSHIN으로 보고, MUSHIN ON/OFF로 무장·해제하세요. 리플래시 불필요: 선택은 플래시에 남고, MEDITATION의 플래셔 브리지는 건드리지 않습니다.

확인

USB 콘솔을 열고 JIGUANG 이야기를 읽으세요: 자세는 MEDITATION, 브리지는 켜져 있고, 자이로는 수신기가 아니라 근육에서 보고합니다.
