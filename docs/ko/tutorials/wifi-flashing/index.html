Pteronaut-Egg로 WiFi 플래싱

완전히 WiFi로 플래싱하고 업데이트하세요 — 케이블, FTDI, UART 없이, 영원히.

Pteronaut-Egg는 수신기에 상주하는 아주 작은 WiFi 부트스트랩(~294 KB)입니다. 그 유일한 역할은 전체 PteronautOS 펀웨어를 WiFi로 받아 준비하는 것이므로 케이블이 전혀 필요 없습니다.

ESP8285에는 ~1 MB 플래시 영역이 하나뿐입니다. 전체 이미지(~636 KB)는 자체 여유 준비 공간에 맞지 않아 WiFi로 스스로 업데이트할 수 없습니다. Egg는 들어갈 만큼 작고, 전체 이미지는 Egg를 되돌려 플래싱할 만큼 작아서 끝없는 Egg ↔ 전체 순환이 이어집니다.

01 — Egg 받기

미리 빌드된 Pteronaut-Egg 이미지를 다운로드하세요. 설정과 무관한 고정 부트스트랩이라 설정도 빌드도 필요 없습니다.

pteronaut-egg.bin 다운로드

02 — 에그 플래시하기 (처음)

수신기는 순정 ExpressLRS로 제공됩니다 — 에그가 아닙니다. 에그를 한 번 설치하되, 전적으로 WiFi로, 수신기 자체 WebUI를 통해 하세요. 케이블은 절대 필요 없습니다.

수신기에 전원을 공급하세요. 순정 ExpressLRS가 WiFi 액세스 포인트를 엽니다. 아래 기본 ExpressLRS 자격 증명으로 연결한 뒤 WebUI를 여세요.

필드 값
WiFi 네트워크 (AP) ExpressLRS RX
WiFi 비밀번호 expresslrs
업로드 페이지 WebUI → Firmware Update

Firmware Update 페이지에서 pteronaut-egg.bin을 업로드하고 수신기가 egg로 재부팅될 때까지 기다리세요.

03 — 전체 펌웨어 받기

전체 펀웨어는 Fossil Etcher에서 매번 새로 빌드됩니다. 수신기, 믹서, 설정을 고르고 최신 이미지를 브라우저에서 바로 다운로드하세요. PlatformIO 없이요.

Fossil Etcher 열기

Etcher는 매번 소스에서 현재 PteronautOS를 빌드하므로 항상 모범 사례 기본값이 적용된 최신 펀웨어를 받게 됩니다.

04 — 에그에 연결하기

수신기에 전원을 공급하세요. 에그가 WiFi 액세스 포인트를 엽니다; 아래 자격 증명으로 연결한 뒤 브라우저에서 업로드 페이지를 여세요 (pteronaut-egg.local, 또는 192.168.4.1 대체).

필드 값
WiFi 네트워크 (AP) PTERONAUT-EGG
WiFi 비밀번호 hatchnatural
업로드 페이지 pteronaut-egg.local

05 — 전체 펌웨어 업로드하기

Egg의 업로드 페이지에서 Fossil Etcher에서 받은 전체 펀웨어를 ASCII Egg 위로 끌어다 놓으세요. Egg가 이를 준비하고 전체 PteronautOS로 재부팅합니다.

06 — 이후 모든 업데이트

이제부터 업데이트는 WiFi 업로드 두 번과 케이블 0개입니다. 전체 PteronautOS는 표준 ELRS WebUI를 실행합니다. Firmware Update 페이지를 열어 Egg를 되돌려 업로드한 뒤 새 전체 펀웨어를 업로드하세요. 이 순환이 무한히 반복됩니다.

WiFi 네트워크 비교

각 단계는 고유한 WiFi 네트워크와 비밀번호, 그리고 다른 업로드 페이지를 사용합니다. 전체 지도입니다:

단계 WiFi 네트워크 (AP) 비밀번호 업로드 페이지
순정 ExpressLRS (수신기에 탑재) ExpressLRS RX expresslrs WebUI → Firmware Update
Pteronaut-Egg PTERONAUT-EGG hatchnatural pteronaut-egg.local
전체 PteronautOS Pteronaut OS flynatural WebUI → Firmware Update

브릭 위험 (솔직히)

모든 무선 플래싱처럼, WiFi가 아예 시작되지 않는 고장난 전체 이미지만이 유선 복구를 강제합니다. 정상 사용에서는 Egg가 케이블을 완전히 없월니다 — 케이블 없이, 영원히.

Fossil Etcher는 WiFi 및 UART 워크플로우용 공용 플래싱 도구입니다. 브라우저에서 전체 펀웨어를 빌드하거나 Web Serial로 플래싱할 수 있습니다. PlatformIO 불필요.
