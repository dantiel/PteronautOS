튜토리얼 01

PteronautOS 플래싱

CYCLONE ELRS 2.4GHz 7CH PWM RX 수신기를 예로 헤르메틱 펌웨어를 빌드하고 설치합니다.

브라우저에서 바로 펌웨어를 빌드하고 플래시하세요 — 툴체인도 드라이버도 필요 없습니다. Chrome, Edge과 Opera는 USB로 플래시하고, 다른 브라우저는 .bin을 다운로드합니다.

온라인으로 플래시

PteronautOS는 다른 수신기 보드도 지원합니다. ESP8285를 공유한다고 배선이 동일하지는 않습니다: 노출된 GPIO, 채널 할당, 프로그래밍 연결, PCB 리비전이 다를 수 있습니다. 아래 전원 및 CH2/CH3 배선은 이 CYCLONE 예시에 적용됩니다. 다른 수신기를 연결하기 전에 보드 핀아웃과 지원 하드웨어 구성을 확인하세요.

전원을 연결하기 전에 날개 메커니즘에서 추진 부하를 제거하고 어떤 서보도 단단한 멈춤에 부딪히지 않도록 하세요. 플래싱은 전기 작업입니다. 절차 내내 기체가 기계적으로 안전해야 합니다.

01 · 펌웨어 빌드

먼저 WebUI를 빌드하세요 — 수신기 펌웨어에 내장되는 인터페이스입니다. 이 단계에는 Node.js 20 이상과 npm이 필요합니다. I18N_LOCALES 플래그는 컴파일할 언어를 선택합니다. 아래 예시는 이 튜토리얼의 언어와 영어를 포함합니다. 플래그를 생략하면 11개 언어가 모두 포함됩니다.

cd src/html && nvm use 20 && I18N_LOCALES=ko,en npm run build:pteronautos

저장소를 클론하고 PlatformIO를 설치한 뒤 저장소 루트에서 다음 명령을 실행하세요. PlatformIO 프로젝트는 src에 있습니다. 이 명령은 이 예시에 쓰이는 전용 ESP8285 수신기 환경을 빌드합니다.

cd ../.. && pio run -d src -e PteronautOS_ESP8285_2400_RX

02 · 수신기 연결

이 CYCLONE 수신기에는 3.3V 출력이 아니라 FTDI 어댑터의 5V 전원 출력을 수신기 공급에 사용하세요. UART 연결은 채널 2와 3의 신호 핀에 있으므로 별도 UART 패드를 찾을 필요가 없습니다.

FTDI 어댑터 수신기 연결
GND GND (−)
5 V / VCC 공급 (+)
TX CH3 신호 — 수신기 RX (GPIO3)
RX CH2 신호 — 수신기 TX (GPIO1)

5V 설정은 수신기 전원을 뜻합니다. 어댑터 문서를 확인하세요: 공급 출력이 5V여도 TX/RX는 ESP8285 호환 3.3V 로직을 사용해야 합니다. 동시에 두 번째 전원을 연결하지 마세요.

03 · 부트로더 진입

BOOT(GPIO0)을 누른 채 FTDI USB 케이블을 뽑았다 다시 연결하고, BOOT을 약 1초간 유지한 뒤 놓습니다. 플래싱 스크립트는 자동 리셋을 수행하지 않으므로 실행 전에 수동으로 부트로더에 진입하세요.

04 · 이미지 쓰기

리포지토리 루트에서 제공된 플래시 스크립트를 실행합니다. 선택한 언어로 WebUI와 펌웨어를 빌드하고, PlatformIO 번들 플래시 도구와 빌드된 펌웨어를 찾아 직렬 포트를 선택한 뒤 필요한 플래시 설정으로 이미지를 기록합니다.

아래 --lang 플래그는 이 튜토리얼의 언어를 직접 빌드에 포함합니다. 생략하면 대화식으로 선택합니다 — 모든 언어, 일부 선택 또는 재빌드 건너뛰기.

./scripts/flash.sh --lang ko

자동 포트 선택은 macOS /dev/cu.* 장치를 찾습니다. 여러 시리얼 장치가 연결되어 있거나 다른 운영체제를 사용 중이면 수신기 어댑터 포트를 명시적으로 선택하세요. 아래 예시를 실제 장치 경로로 바꾸세요.

./scripts/flash.sh --lang ko --port /dev/cu.usbserial-XXXX

펌웨어를 쓰지 않고 부트로더 통신을 확인하려면 옵션인 체크 모드를 사용하세요. 실패하면 다시 시도하기 전에 BOOT 전원 사이클을 반복하세요.

./scripts/flash.sh --port /dev/cu.usbserial-XXXX --check

05 · 설치 확인

BOOT을 누르지 않은 채 수신기의 전원을 껐다 켭니다. WiFi 액세스 포인트와 WebUI가 사용 가능해졌는지 확인하세요 (SSID: Pteronaut OS , 비밀번호: flynatural ), 그런 다음 구성을 불러오고 서보를 다시 연결하기 전에 타깃 이름을 확인하세요.

계속해서 하드웨어 페이지 핀 맵과 리비전별 배선 노트를 확인하세요.
