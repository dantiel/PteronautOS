호환 수신기

PWM 출력을 제공하는 ESP8285 + SX1280/SX1281 기반 ExpressLRS 2.4GHz 수신기 — 또는 CRSF→PWM 변환기와 함께 쓰는 CRSF 수신기 — 는 PteronautOS를 실행할 수 있습니다. 가격은 대략적인 값이며 지역에 따라 다릅니다.

주요 사양

MCU ESP8285 @ 80 MHz, 1 MB 플래시
라디오 ExpressLRS 2.4 GHz (SX1280)
자이로 I2C의 MPU6050 (GY-521)
서보 3 PWM 채널 — 왼쪽 날개, 오른쪽 날개, 크레스트 러더

배선

세 개의 서보 채널과 I2C 버스의 MPU6050. 전체 핀 맵, I2C 배선, v1.0/v1.1 리비전 차이는 PWMP7 가이드에 있습니다.
