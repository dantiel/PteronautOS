Учебник 08

Прошивка по WiFi с Pteronaut-Egg

Прошивайте и обновляйтесь полностью по WiFi — без кабеля, без FTDI, без UART, никогда.

Pteronaut-Egg — это крошечный WiFi-бутстрап (~294 КБ), который живёт на приёмнике. Его единственная задача — принять полную прошивку PteronautOS по WiFi и подготовить её — так что кабель вам не нужен вовсе.

У ESP8285 одна область флеш-памяти ~1 МБ. Полный образ (~636 КБ) не помещается в собственное свободное пространство для подготовки, поэтому не может обновиться по WiFi. Egg достаточно мал, чтобы поместиться, а полный образ достаточно мал, чтобы вернуть egg обратно — замыкая бесконечный цикл egg ↔ полный.

01 — Получите egg

Скачайте готовый образ Pteronaut-Egg. Это фиксированный бутстрап, не зависящий от конфигурации — без настроек и сборки.

Скачать pteronaut-egg.bin.gz

02 — Получите полную прошивку

Полная прошивка всегда собирается заново в Fossil Etcher — выберите приёмник, микшер и конфигурацию, затем скачайте новейший образ прямо из браузера. Без PlatformIO.

Открыть Fossil Etcher

Etcher каждый раз собирает актуальный PteronautOS из исходного кода, поэтому вы всегда получаете новейшую прошивку с настройками по умолчанию, соответствующими лучшим практикам.

03 — Прошивка не нужна

Ваш приёмник поставляется с уже установленным Pteronaut-Egg — прошивать нечего и кабель никогда не нужен. Если egg когда-либо будет стёрт, вы можете восстановить его по WiFi из WebUI полной прошивки.

04 — Подключитесь к egg

Включите приёмник. Egg открывает точку доступа WiFi; подключитесь к ней и откройте страницу загрузки egg в браузере.

Поле Значение
Сеть WiFi (AP) PTERONAUT-EGG
Пароль WiFi hatchnatural
Страница загрузки (mDNS, с запасным 192.168.4.1) pteronaut-egg.local

05 — Загрузите полную прошивку

На странице загрузки egg перетащите полную прошивку, скачанную из Fossil Etcher, на ASCII-egg. Egg подготовит её и перезагрузится в полный PteronautOS.

06 — Каждое будущее обновление

Отныне обновление — это две загрузки по WiFi и ноль кабелей. Полный PteronautOS запускает стандартную WebUI ELRS — откройте её страницу Firmware Update, загрузите egg обратно, затем загрузите новую полную прошивку. Цикл повторяется бесконечно.

Риск окирпичивания (честно)

Как и при любой прошивке по воздуху: только сломанный полный образ, чей WiFi никогда не запускается, потребует проводного восстановления. В обычном использовании egg полностью убирает кабель — без кабеля, никогда.

Fossil Etcher — это общий инструмент прошивки для сценариев WiFi и UART — скачайте egg или соберите полную прошивку напрямую, всё из браузера.
