Учебники

Практические руководства по подготовке аппаратуры, установке герметичной прошивки и оживлению нового планера PteronautOS.

PteronautOS — не обычный мультироторный стек. Он переводит управление CRSF в скоординированный взмах крыльев для двух сервоприводов крыла и гребневого руля, при этом стабилизация Зефир остаётся опциональной и изящно деградирует.

Начните с руководства по прошивке ниже. Поздние руководства охватят распайку приёмника, привязку, первый управляемый взмах и настройку формы волны через WebUI. Каждая процедура держит в поле зрения ключевые правила проекта: детерминированный тайминг, центрированное поведение failsafe и отсутствие блокирующей работы в цикле полёта.
